## Approval checklist

- [ ] Topic is not a silent duplicate of a prior reel.
- [ ] Three hook concepts were considered.
- [ ] One hook and structure were approved.
- [ ] Every important claim has visual proof.
- [ ] Primary subjects are explicitly identifiable without narration; no anonymous icon or silhouette carries an essential claim.
- [ ] Full-bleed layers fill the actual camera frame; safe-area protection is applied only to semantic overlays.
- [ ] Facts, creator provenance and licenses are recorded.
- [ ] Word count and estimated duration are realistic.
- [ ] Actual narration alignment is not claimed prematurely.
- [ ] Natural narration was synthesized/recorded first and scene windows were derived from measured segment durations.
- [ ] Captions are safe-area checked.
- [ ] Narration-first mix plan is approved.
