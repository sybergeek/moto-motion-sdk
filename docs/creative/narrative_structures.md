# Narrative structure templates

Choose the structure that fits the verified claim. These are editorial patterns, not mandatory formulas.

## A. Mystery → explanation → reveal

Use when the opening visual contains an unexplained detail. Ask one question, introduce the mechanism, then show the answer.

## B. Prediction → comparison → result

Use for fair A/B demonstrations. Put both candidates at the same starting condition, state the comparison rule, run the test, then reveal the result.

## C. Myth → evidence → correction

Use when a common assumption can be tested with clear evidence. State the assumption accurately, show evidence, then replace it with a narrower rule.

## D. Problem → mechanism → solution

Use for driver technique or engineering explainers. Establish the practical problem, show the causal mechanism, then state the actionable principle.

## E. Surprising result → race/championship analysis → payoff

Use for standings, strategy or historical moments. Open with the contradiction, verify the event facts, explain the chain, then return to the opening result.

For each structure record: why it fits, what could confuse viewers, the first useful answer, the proof scene and the final payoff.
