# RaceXplained hook pattern library

Use these as starting points, not formulae. For every reel, propose three genuinely different concepts and reject any that the verified footage or explanation cannot support.

| Pattern | Spoken hook template | First-frame visual | Viewer question | Promised payoff | Limitation |
|---|---|---|---|---|---|
| Counterintuitive fact | “The [apparently worse] move can be faster.” | Two outcomes side by side | Why would the slower-looking move win? | Show the mechanism and measured comparison | Requires a defensible comparison, not a slogan |
| Visual mystery | “One detail decides this corner.” | Tight crop with one highlighted detail | What is the detail doing? | Zoom out to the complete mechanism | Do not hide context so long that the claim becomes vague |
| Prediction challenge | “Which bike reaches the straight first?” | Two labeled bikes at the same start | Which one should I pick? | Run the comparison and reveal the result | Both paths and the scoring rule must be visible |
| Unexpected result | “He lost the race—and won the season.” | Contradictory result cards | How can both be true? | Resolve with standings or points | All numbers and event facts must be verified |
| Myth versus reality | “Shorter does not always mean faster.” | Myth label over a concrete diagram | What assumption is wrong? | Replace the myth with a usable rule | Avoid attacking a straw-man version of the myth |
| Technical demonstration | “Watch what changes when the radius doubles.” | Animated radius/force diagram | What changes, and why? | Show the equation and a visual consequence | Label simulations as illustrative |
| Before-and-after comparison | “Same corner; different exit.” | Matched frames or synchronized paths | Which setup produces the exit? | Show the changed variable | Match framing and timing so the comparison is fair |
| Racing strategy dilemma | “Do you defend the inside or sacrifice the corner?” | Inside line versus exit line | Which trade-off is faster? | Explain total time, not just distance | Do not generalize a single illustrative model to every circuit |

## Hook proposal format

For each candidate, fill: spoken hook; first-frame visual; viewer question; promised payoff; supporting footage/animation; factual limitations; required asset; confidence. Select one only after a human editorial review.
